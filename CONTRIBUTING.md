# Contributing to RYKO

Thanks for your interest in RYKO!

RYKO is an early-stage open-source project and feedback, ideas and
contributions are welcome.

## How you can help

You can contribute by:

- Suggesting new creator tools
- Reporting bugs
- Improving the documentation
- Improving the user interface
- Adding new functionality
- Testing the project
- Submitting pull requests

## Getting started

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Test your changes
5. Open a pull request

## Ideas

If you have an idea for a feature, feel free to open a GitHub issue
before starting development.

## Code quality

Please keep the code simple, readable and accessible to beginners.
